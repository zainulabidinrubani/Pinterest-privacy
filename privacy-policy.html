App: pinterest-autopin
Last updated: October 2026

Overview

pinterest-autopin is a personal-use automation tool that posts AI-generated pin content to the developer's own Pinterest account on a scheduled basis. It does NOT collect, store, or share any personal data from Pinterest end users. It does NOT act as a service offered to other Pinterest users — there are no sign-ups, logins, or user accounts.

What this app accesses

The app uses the Pinterest API v5 with the following scopes:

  • boards:read — to list the developer's own boards (used only to look up the configured board_id).
  • boards:write — to create pins on the developer's own boards.
  • pins:write — to create pins (with title, description, image, and an affiliate link as the destination URL) on the developer's own account.
  • user_accounts:read — to verify the OAuth token is active.

All access is scoped to the developer's own Pinterest account via an OAuth token explicitly granted by that account. No other Pinterest user's data is read, modified, or stored.

What data is stored

  • Locally (developer-side only): the queue of products to pin (product name, affiliate link, source image URL) is stored in a CSV file or a private Google Sheet owned by the developer.
  • Generated images: AI-generated pin images are saved to a local directory on the developer's machine / GitHub Actions runner, then uploaded to Pinterest. They are not shared with any third party.
  • Pin metadata: the pin ID returned by Pinterest is written back into the local queue for tracking. No other Pinterest user data is stored.

Third-party services this app calls

  • Pinterest API v5 — to create pins on the developer's own account.
  • Google Gemini API (Google AI Studio free tier) — to generate SEO copy and stylized pin images from product photos. The product name, affiliate link, and source image are sent to Google for processing.
  • Google Sheets API (optional, only if queue backend is set to sheets) — to read/write the developer's own private spreadsheet.
  • GitHub Actions — to run the hourly schedule; GitHub sees only the repository code and GitHub Secrets (no plaintext credentials).

AI-generated content disclosure

Every pin created by this app is marked with an [AI-generated] prefix in the alt_text field, in compliance with Pinterest's Acceptable Use Policy. Image-generation prompts instruct the model to preserve the original product's appearance — shape, colour, and brand markings are not altered.

Affiliate links

Pins created by this app link to affiliate URLs supplied by the developer. Those URLs may set their own cookies and tracking pixels governed by the destination site's own privacy policy. This app does not control or benefit from third-party tracking beyond the affiliate commission disclosed by the destination merchant.

Data retention

  • Queue rows: retained indefinitely by the developer for tracking which products have been pinned. The developer may delete them at any time by editing the local queue file or Google Sheet.
  • Generated images: kept until the GitHub Actions cache is evicted (~7 days) or until the developer deletes them locally.
  • Access tokens: stored as GitHub Secrets; never logged, never written to disk in plaintext.

Your rights

This app does not collect personal data from you, so there is no personal data to access, correct, or delete under GDPR/CCPA. If you believe a pin posted by this app violates your rights (e.g. it uses your copyrighted product image without permission), contact the developer at the email above and the pin will be removed within 5 business days.
